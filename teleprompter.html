How it works

Prompt your script in 3 easy steps.

01

Paste Your Script

Drop your script into the text area. Add blank lines between sections — they render as visible section breaks so you know when to pause naturally.

02

Set Your Pace

Pick a scroll speed, font size, line height and theme. Enable mirror mode for a beam-splitter rig, turn on the reading guide line, and set a countdown so you can get into position.

03

Start & Read

Press space or the Start button. The script scrolls smoothly and you can adjust speed on the fly with the arrow keys. Press F for distraction-free fullscreen.
