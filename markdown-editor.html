What is it?

The Free Online Markdown Editor

Markdown is a lightweight plain-text formatting syntax created by John Gruber in 2004. Instead of clicking buttons for bold, italic or headings, you type simple symbols like # for headings, ** for bold, or - for bullet lists. The result is text that is completely readable as plain text, but can be rendered into fully formatted HTML wherever you need it.

Our free Markdown editor gives you the best of both worlds: a clean editor on the left where you write in Markdown, and a live preview on the right that renders exactly how the final document will look. Every keystroke updates the preview instantly, so you never have to switch tabs or refresh anything.

The editor supports GitHub-flavoured Markdown, which is what you need for writing README files, documentation, blog posts and any content destined for GitHub, GitLab, Notion, Obsidian, or a static-site generator like Jekyll or Hugo. Tables, task lists, fenced code blocks, strikethrough and autolinks all render correctly.

Everything runs locally in your browser and autosaves to your own device — nothing is ever sent to a server. You can start a blank document, import a .md file, paste from your clipboard, and export your finished work as a .md or styled .html file whenever you are ready.
