What is it?

The Free Color Code Converter

A color converter translates a single color value between the different color models used across design, web development and print. Each model describes the same color in its own way: HEX and RGB use red, green and blue channels for screens, HSL and HSV express hue, saturation and lightness/value for designers, CMYK describes the cyan, magenta, yellow and black inks used in print, and LAB is a device-independent model that approximates human vision.

Because the same color is written differently depending on the medium, moving a color from a Figma file into CSS, then into a print-ready PDF, means converting formats at every step. Our online color converter does all six conversions at once from a single input — so you never have to chain tools together or hunt for a formula.

The tool also handles a paste-any-format workflow. Rather than forcing you to pick the right input type, the parser reads whatever you paste: a HEX code, an rgb() string, an hsl(), hsv(), cmyk() or lab() value. It detects the format, converts to RGB as the hub model, then outputs every other representation.

Everything happens client-side in JavaScript. Your colors are never sent to our servers, and no data is stored. That makes it safe for brand palettes, unreleased product colors and any other confidential work.

Questions

Frequently Asked Questions.

A color converter is a tool that translates a color value from one color model into another — for example, converting a HEX code into its equivalent RGB, HSL, HSV, CMYK or LAB representation. Designers use it to move a color between web code, design software, and print output without losing accuracy.

HEX and RGB are both additive models used on screens, where colors are produced by mixing red, green and blue light. HSL and HSV are alternative representations of the same RGB model that map more naturally to how humans think about hue, saturation and brightness. CMYK is a subtractive model used for print, where cyan, magenta, yellow and black inks are combined on paper. LAB is a device-independent model designed to approximate human vision; it is used for color matching across different devices and gamuts.

Split the six-digit HEX code into three pairs — for example, #4A90E2 becomes 4A, 90 and E2. Convert each pair from hexadecimal to decimal: 4A is 74, 90 is 144 and E2 is 226. The result is RGB(74, 144, 226). Our converter does this instantly for you and also shows the HSL, HSV, CMYK and LAB equivalents.

CMYK is a subtractive print model with a much smaller gamut than RGB. Bright, saturated screen colors — especially vivid greens, cyans and oranges — simply cannot be reproduced with standard process inks. The CMYK numbers produced here are an approximation based on the standard conversion formula; for print-critical work, always let your print provider convert using their ICC profile.

CIELAB (or L*a*b*) describes colors using three axes: L* for lightness, a* for the green–red axis, and b* for the blue–yellow axis. Because it is designed to be perceptually uniform and device-independent, LAB is used in color management, ICC profiles, paint matching and anywhere exact color matching across different media matters.
