# Contributing to the Project

First off, thank you for taking the time to contribute! 🎉 Our goal is to keep this project helpful, clean, and easy to use. 

Please take a moment to review the guidelines below to help make your contribution process smooth.

---

## Code of Conduct
By participating in this project, you agree to abide by our **Code of Conduct**. Please report unacceptable behavior to the project maintainers.

---

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug in the code or a broken link/feature:
* Check the **Issues** tab to see if the issue has already been reported.
* If not, open a new issue using the **Bug Report** template.
* Include clear steps to reproduce the issue, along with browser or device details if applicable.

### 2. Suggesting Enhancements
Have an idea for a new feature, article topic, or improvement?
* Open a **Feature Request** issue to pitch your idea.
* Clearly explain why this enhancement would be useful to other users.
